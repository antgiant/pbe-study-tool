# PBE Study Tool
A tool for practicing Pathfinder Bible Experience (PBE) fill in the blank questions

## Moving to the PBE Quiz Builder

Fill in the blank practice now lives in the [PBE Quiz Builder](https://quiz.pbefocus.com/), which adds printable
quizzes, PowerPoint decks, difficulty-based blanks and more. This tool shows a banner with a **Move to the Quiz
Builder** button that carries your presets and chapter choices over (they travel in the link, since the two sites
can't share storage). On the date in `REDIRECT_AFTER` (`src/migration.js`, currently January 1, 2027) this page
redirects there automatically.
